# Local Business Website

Complete website solution for three business types:
- 🍽️ Restaurant/Café
- 💪 Gym/Fitness Studio
- 💇 Salon/Spa

## Features
- Responsive design for all devices
- Online booking/reservation system
- User authentication
- Contact forms with email integration
- Admin dashboard
- Image galleries
